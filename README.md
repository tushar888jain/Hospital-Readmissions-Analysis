# Hospital Readmissions Analysis

An interactive SQL and Power BI project analyzing hospital patient encounter data to uncover the key drivers behind 30-day readmissions.

# Overview

Hospital readmissions are costly, both financially and in terms of patient outcomes, and are widely used as an indicator of care quality. This project looks at hospital patient encounter data to understand which patients are most likely to be readmitted and why, with the goal of informing better discharge planning, medication management, and follow-up care.

The data was cleaned and queried to surface readmission patterns across age, existing health conditions, medication changes, and prior visit history, then brought together into an interactive dashboard covering patient demographics, clinical drivers, medication trends, and utilization history, with filters to explore each pattern in more depth.

# Conclusion

Patients with multiple existing health conditions, a history of frequent hospital visits, or a recent medication change show the highest readmission risk, with age adding a further layer on top of these patterns. Together, these findings offer a practical, data-backed starting point for reducing readmissions through targeted discharge planning and follow-up care.
